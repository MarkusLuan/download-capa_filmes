## Download de capas de filmes

O script foi feito para extrair um CSV em JSON para utilizar em uma outra aplicação e também para fazer o download automatico das capas dos filmes...

### Dados Utilizados
- O site onde baixei o CSV foi o [Kaggle](https://www.kaggle.com/)
    - Você pode baixar o mesmo .CSV em [https://www.kaggle.com/datasets/harshshinde8/movies-csv/data](https://www.kaggle.com/datasets/harshshinde8/movies-csv/data)
    - Gostaria de ter pego em português, porém não encontrei. (ainda cheguei a pedir ao GPT, mas só enrolava)
- O site onde é feito a consulta das capas dos filmes foi o [CineMaterial](https://www.cinematerial.com/)
